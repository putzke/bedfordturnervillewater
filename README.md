# Bedford Turnerville Regional Water Study

Public outreach site and survey for the WWDC Bedford & Turnerville Regional Supply Level II Study.
Static site for GitHub Pages: `index.html`, `survey/index.html`, assets in `assets/`.
Survey answers post to a Google Sheet through the Apps Script in `apps-script/` (see `SETUP.md`).

Live: https://bedfordturnervillewater.com
